# 営業支援ポータル HTML画面モック

> 本モックは画面構成と操作イメージを確認するための静的資料です。画面が存在することや構文検査の成功は、実装済み・動作保証済みであることを意味しません。

[画面モックを開く](index.html)

## 2026-09-21 照合後の反映

- 問い合わせ対象は「ポータルサイト」、各ツール、「その他」に統一。管理検索も同じ対象を扱う。
- 問い合わせ一覧から詳細へIDを渡し、2件それぞれの送信者・分類・対象・担当者・状態・備考・本文を一致させる。
- Web起動の案内は「別タブ」に統一する。
- お知らせ編集は利用者による動作確認を受け、今回の修正対象外とした。編集関数・イベントは変更しない。
- TSV件数・容量、バージョン形式は常時の制限案内を追加せず、実装では取込／入力検証のエラー時だけ表示する。静的モックでの保存・取込検証実装は対象外。
- ツール状態バッジの初期色はこのモックを正とし、本実装ではCodeMaster.ColorCodeで背景色を変更可能とする。モックの固定CSSはDB連携実装へそのまま流用しない。

画像版の画面イメージを、ブラウザーで表示・操作できる静的HTMLへ置き換えたものです。画面上部のセレクトボックスまたは各リンクから画面を切り替えられます。

- 実DB、認証、メール送信、ファイル保存には接続しません。
- 入力内容やボタン操作は保存されません。
- 関連資料は「編集」「関連資料追加」で一覧下のフォームを開き、「キャンセル」で閉じます。編集時は表示名だけの変更も確認できます。保存やファイル差し替えは実行しません。
- ユーザー一覧の検索・条件クリアはダミーデータに対して動作し、ロック状態も絞り込めます。「有効／無効」と「ロック中／ロックなし」は別項目です。
- ユーザー取込は`Email`、`DisplayName`、`RoleCode`の3列を案内します。ユーザー編集では一般ロールA～Dを選択する例を示し、管理者への変更は扱いません。
- ツールのカテゴリ表示・絞り込みは残し、並び順はカテゴリをまたぐ全ツール共通の順序として案内します。ツールとロールの割当てはDB運用のため編集画面を設けません。
- 全ツール一覧ではツール名から詳細へ移動でき、別の「コンテンツ」列にWeb起動・配布アプリ・資料の直接操作を示します。限定公開の一般ユーザー向け行には操作リンクを出しません。静的モックの直接操作は案内表示だけで、実際の起動・ダウンロードは行いません。
- ログ管理（A003）画面とログ出力ボタンは削除しました。ログ記録とSQLによる運用抽出は静的モックの対象外です。
- ユーザー名からパスワード変更・ログアウトのメニューを開けます。ログアウトはログイン画面への模擬遷移で、実認証には接続しません。
- 問い合わせの個別回答有無の案内は設けません。カテゴリは汎用コードマスタ、対象はポータルサイト・各ツール・その他から構成します。画面モック内の名称は表示例です。
- 関連資料は「編集」「関連資料追加」で一覧下のフォームを開き、「キャンセル」で閉じます。編集時は表示名だけの変更も確認できます。保存やファイル差し替えは実行しません。
- ユーザー一覧の検索・条件クリアはダミーデータに対して動作し、ロック状態も絞り込めます。「有効／無効」と「ロック中／ロックなし」は別項目です。
- ユーザー名からパスワード変更・ログアウトのメニューを開けます。ログアウトはログイン画面への模擬遷移で、実認証には接続しません。
- 問い合わせの個別回答有無の案内は設けません。カテゴリは汎用コードマスタ、対象はポータルサイト・各ツール・その他から構成します。画面モック内の名称は表示例です。
- 正確な動作・入力条件・状態制御は `../02_画面・機能設計.md` と `../04_DB設計.md` を正とします。
- 旧PNGは比較用として `../images/` に残しています。
- 同名の画面生成関数が複数残っており、後に定義された関数が有効になります。実装へ流用せず、画面確認専用として扱います。
- 新規ツール登録はモックに含めません。所定SQL等で手動登録し、初期状態は非公開とします。
- 現在のバージョン未選択または履歴0件の場合、利用者向け表示では`Ver.1.0.0`を補完します。モックの固定表示はDBへの履歴登録を表しません。
- 履歴はバージョン番号順で扱い、最後の1件は削除できません。ファイル切戻しに必要な旧ファイルとバージョンの対応確認は運用担当者の責任です。
- 送信後のお知らせも編集できます。表示中の最終送信日時は過去の送信成功日時であり、編集後の本文が送信済みであることを保証しません。
- 検索、保存、ユーザーTSV取込、メール、アップロード等のボタンは、配置と遷移の確認用です。実DB、認証、ファイル、SMTPには接続しません。
