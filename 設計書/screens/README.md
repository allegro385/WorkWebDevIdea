# 営業支援ポータル HTML画面モック

> 本モックは画面構成と操作イメージを確認するための静的資料です。画面が存在することや構文検査の成功は、実装済み・動作保証済みであることを意味しません。

[画面モックを開く](index.html)

画像版の画面イメージを、ブラウザーで表示・操作できる静的HTMLへ置き換えたものです。画面上部のセレクトボックスまたは各リンクから全20画面を切り替えられます。

- 実DB、認証、メール送信、ファイル保存には接続しません。
- 入力内容やボタン操作は保存されません。
- 関連資料は「編集」「関連資料追加」で一覧下のフォームを開き、「キャンセル」で閉じます。編集時は表示名だけの変更も確認できます。保存やファイル差し替えは実行しません。
- ユーザー一覧の検索・条件クリアはダミーデータに対して動作し、ロック状態も絞り込めます。「有効／無効」と「ロック中／ロックなし」は別項目です。
- ユーザー名からパスワード変更・ログアウトのメニューを開けます。ログアウトはログイン画面への模擬遷移で、実認証には接続しません。
- 問い合わせの個別回答有無の案内は設けません。カテゴリ・対象の選択肢は暫定例で、汎用コードマスタの初期データ作成時に検討します。

- ユーザー一覧の検索・条件クリアはダミーデータに対して動作し、ロック状態も絞り込めます。「有効／無効」と「ロック中／ロックなし」は別項目です。

- 正確な動作・入力条件・状態制御は `../02_画面・機能設計.md` と `../04_DB設計.md` を正とします。
- 旧PNGは比較用として `../images/` に残しています。
- 同名の画面生成関数が複数残っており、後に定義された関数が有効になります。実装へ流用せず、画面確認専用として扱います。
- 新規ツール登録はモックに含めません。所定SQL等で手動登録し、初期状態は非公開とします。
- 現在のバージョン未選択または履歴0件の場合、利用者向け表示では`Ver.1.0.0`を補完します。モックの固定表示はDBへの履歴登録を表しません。
- 履歴はバージョン番号順で扱い、最後の1件は削除できません。ファイル切戻しに必要な旧ファイルとバージョンの対応確認は運用担当者の責任です。
- 送信後のお知らせも編集できます。表示中の最終送信日時は過去の送信成功日時であり、編集後の本文が送信済みであることを保証しません。
- 検索、保存、TSV取込・出力、メール、アップロード等のボタンは、配置と遷移の確認用です。実DB、認証、ファイル、SMTPには接続しません。
